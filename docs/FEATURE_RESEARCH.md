这是常见功能归纳，不是市场占有率排名。项目 JSON 不声称兼容厂商宏文件格式。

状态呈现采用工具型界面的通用规则：保留清楚的状态文字（运行中、监听中、已停止），用低面积的绿色/蓝色/灰色强调状态，不依赖图标像素细节或颜色单独传意。此处是界面设计取舍，并非对某款软件视觉实现的逐像素复刻。

## 实现

手动初始化：构造窗口只创建 DeferredDdKeyboard；点击初始化后工作线程调用 Initialize → DdNativeKeyboard → DD_btn(0)。成功才设置 IsInitialized、开放编辑与注册快捷键。失败保持锁定且写日志，需重启；关闭期间初始化返回不会重新注册热键。

初始化入口不调用 DD_key，不启动重复。界面和命令均检查可用状态。DD 自身的 Win/鼠标副作用尚未根治。

配置复制包含独立的步骤对象。导入使用已有版本迁移机制，完整校验后追加；导出当前配置、覆盖前对话框确认，禁止选择当前主配置路径。非法按键、间隔、快捷键重复或序列/快捷键冲突均被拒绝。

## 配置区布局调整

保存配置移至“我的配置”右侧，与新建、直接选择卡片放在一起；顶部仅保留置顶。名称及复制/导入/导出/删除集中于配置区，低频操作放在“管理配置”展开项中。快捷键使用紧凑卡片，按键序列紧随其后，去除重复分隔线和多余留白。

界面拆分为 ProfileSelector、HotkeyEditor、ProfileEditor，保留原命令及状态绑定。构建零警告零错误；用假数据渲染实际 WPF 控件检查 700×800 和 540×460 布局，小窗口配置区可滚动，顶部启停与配置区保存可见。本轮仅界面修改，没有初始化 DD 或发送按键。

## 方案编辑向导 · 1.3.0

方案编辑迁移到单独窗口并拆成触发、流程、重复三个步骤。当前工作流模式写入配置 v5；v1-v4 配置根据步骤数量迁移为单键或顺序模式。颜色触发配置折叠在触发页，当前窗口在采样时最小化。运行状态使用文字与窄色条，不用窗口标题中的 Unicode 方块/圆点字符。编辑与运行继续使用同一份 ViewModel 和既有调度、颜色采样服务。

本轮回归：Core 45 项通过。Windows 侧其余 42 项通过，1 项真实桌面颜色/鼠标交互测试在等待监听就绪时超时；该测试依赖交互桌面，本次环境未能完成验证。WPF Debug 构建通过，0 警告、0 错误。未初始化 DD，未发送按键。

## 编辑窗口启动崩溃修复 · 1.3.1

Windows Error Reporting 记录了未处理异常：只读的 `IsSingleKeyMode` 被 `RadioButton.IsChecked` 默认按 TwoWay 绑定，WPF 布局时抛出 `InvalidOperationException`。流程类型和重复模式的四个只读状态绑定改为 OneWay。新增 WPF STA 冒烟测试，真实加载并布局编辑窗口，核对四个状态单选项的绑定模式。

回归验证：编辑窗口冒烟测试通过；全套非桌面依赖测试为 Core 45 项、Windows 43 项通过。真实桌面鼠标采样测试仍受当前会话无法启动全局鼠标监听影响，保持单独未通过状态。未初始化 DD，未发送按键。

## 被动热键与方案激活池 · 1.3.2

启停键改为只观察并放行，删除 `RegisterHotKey` 路径。所有方案的开始、停止和备用开始键都绑定到被动接收器；同时触发的方案快照进入有界 FIFO 激活池，单一 runtime 串行执行以保护共享输出设备。全局停止取消当前项、清空队列、停止颜色监听并释放输出按键。颜色监听按方案独立运行，边沿触发后提交到相同激活池。准备前窗口压缩到 500×320，准备后展开至工作尺寸。

激活池 FIFO 与取消测试通过。Core 测试 45 项通过；Windows 测试 44 项通过，2 项要求实际桌面 `PresentationSource` 的像素测试在当前会话无法建立可见窗口而失败。未初始化 DD，未进行应用内实测。
