# 热键与精简运行窗口修正

2026-11-24：现有日志出现多次 WM_HOTKEY id=1 后没有执行记录，但没有游戏前台失败按键的完整证据，不能认定全是游戏拦截。为参数错误及按键冲突增加明确的拒绝日志。

SystemHotkeys 保留 RegisterHotKey，添加 15ms DispatcherTimer 读取已注册按键的 GetAsyncKeyState 高位，仅在按下边沿触发，匹配修饰键；两种来源按 id 做 150ms 去重。录入期间 Clear 会同时停止轮询对应键，关闭时释放定时器和注册。注册失败不会私自启用冲突按键。轮询不能保证绕过应用输入限制，极短按键可能遗漏。测试使用注入状态验证，并未在游戏内实测。

运行时隐藏编辑区，正常窗口缩到 320px 高；停止恢复原高度，保留置顶和停止操作。最大化时仅隐藏配置。

取消人为的 30ms 间隔下限：允许 1..3600000ms，按住 min(30,max(1,interval/2))ms。80ms 成功基准仍保持按住 30ms。短间隔受 Windows 调度和目标接收能力影响。

验证：27 项测试通过，其中按键状态补充触发、修饰键、按住不重发、Clear 清理和短间隔映射都有覆盖。游戏内热键、窗口变化的实际视觉效果仍待用户复测。
