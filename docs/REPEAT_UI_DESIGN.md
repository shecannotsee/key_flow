# 重复模式交互设计（2026-11-24）

实际访问的参考：

- https://www.opautoclicker.com/ ：官方说明支持无限重复、可更改热键、后台热键及保存设置。本项目采用重复操作为主、快捷键辅助的组织方式；没有照搬鼠标选项。
- https://www.autohotkey.com/docs/v2/lib/WinSetAlwaysOnTop.htm ：文档定义开启、关闭和切换置顶；本项目以明确的“窗口置顶 / 已置顶”按钮控制 WPF Topmost。
- https://www.autohotkey.com/docs/v2/lib/SoundBeep.htm ：文档提供声音提示，并指出同步声音会等待完成。本项目使用独立短 WAV 双音，在后台串行播放，不在输入线程阻塞。

以上网页本轮 HTTP 200，已阅读文字说明；未声称试用了这些软件的全部界面。绿色运行条、灰色停止条、窗口标题和不同双音是本项目的具体设计，用文字、颜色和声音共同表达状态。

本轮变更：移除界面与命令行的 5 秒等待；重复仅显示一个时间参数（间隔），内部按住固定 30ms；保留按键列表及点击录入；开始/停止互斥启用；非法数字绑定错误阻止开始和保存；热键入口也检查错误；启停声音按真实状态转换仅播放一次。

验证：19 项测试通过，包括两秒内开始发送、取消释放、DD 失败处理、提示音 WAV 头/长度及两个声音不同。未在自动化环境确认用户实际听到声音；本机旧窗口仍运行，因此使用 .artifacts/repeat-ui 隔离构建。旧程序不被强行关闭；下次启动脚本会重新构建到原位置，使用原配置。
