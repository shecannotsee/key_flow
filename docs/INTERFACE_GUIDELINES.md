# 界面规范与 1.3.6 调整

2026-11-25 读取官方资料：
- Apple HIG Layout：https://developer.apple.com/design/human-interface-guidelines/layout.md
- Microsoft Fluent 2 Design principles：https://fluent2.microsoft.design/design-principles

原文快照保存于 .artifacts/features。二者支持视觉层级、清晰分组、减少噪声、适应窗口尺寸和渐进展示；没有提供“用户接受度最高”的市场排名。Fluent 按钮详情 URL 返回 404，未作为依据。

采用浅色工具界面：白色内容卡片、低对比背景、8–12px 圆角、统一输入框及选择控件，使用蓝色表示操作/选择，绿色配文字表示参与触发。保留键盘焦点、禁用与输入错误状态。不加入妨碍阅读的装饰动画或材质效果。

主窗口：参与触发总览 → 配置组 → 单个方案。组有独立名称、启用状态和成员 ID，可选择多个方案，也允许同一方案加入多个组。实际参与状态 = 单独开启 OR 任一已开启组包含该方案，去重后监听一次。编辑组独立窗口；组关闭不修改成员的单独参与状态。

编辑窗口：触发页显示名称、快捷键与始终可见的取色开关；流程页用按键卡片与卡片之间的等待连接表示顺序，末尾明确回到首键；重复页直接展示重新计时/忽略两种策略及示例，单键开关模式解释并禁用策略。

删除：每个方案提供直接删除入口，显式传入目标；删除最后一个方案也允许。确认后原子保存，删除组成员引用，失败保留内存数据并提示。新建方案默认不参与触发。空列表不会在重启后自动复活默认方案。

配置 v9：增加稳定方案 ID 与独立 Groups；v8 标签迁移为组，保留原单独参与状态，迁移组默认关闭以免扩大触发范围。导入重新映射 ID，避免导入同一文件时串组。
