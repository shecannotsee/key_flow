# 主界面與方案编辑器 UI 更新 · 1.5.0

## 变更范围

- 建立 `Themes/FluentTheme.xaml`，统一主界面与编辑窗口的按钮、输入框、单选/复选、状态文字、间距及圆角。主界面和编辑器分别加载；配置组窗口与其他窗口维持原有资源。
- 主窗口继续使用已完成的 `MainWorkspace` 信息架构；初始化页、控制命令和业务状态不变。
- 编辑窗口改为 700×620 默认、560×520 最小尺寸。页头、配置名称、三步等宽导航固定；中间内容独立滚动，底部上一步/下一步/保存固定。
- 触发页压缩标题和名称区；开始/停止热键沿用 `HotkeyEditor` 原命令；颜色触发保留框选、激活/未激活色采集、检测、确认时间、颜色值、容差及高级检查。
- 流程页以统一序号、按键行、等待行展示原有步骤；等待仍写入原 `WaitAfterMs`。保留按键录入、添加、删除、上移、下移原命令。
- 重复页紧凑呈现持续/限时、重新计时/忽略触发和时间单位；时间含义改为折叠说明，绑定和业务规则不变。
- 未改配置数据结构、持久化、快捷键监听、激活池或执行核心。`App.xaml` 未全局套用编辑器主题，避免影响范围外窗口。
