# key_flow 1.2.0：颜色激活触发流程

## 安装和测试

关闭正在运行的 key_flow，运行 `dist/key_flow_setup_1.2.0_x64.exe` 更新。安装保留个人配置；首次加载旧配置不自动保存，修改后点击保存。

1. 点击“准备使用”，选择或复制一个配置。
2. 按键序列保留 E，间隔设为 80ms，持续时间设为 6 秒。
3. 展开“屏幕取色与激活判断”，点击“① 划定区域”，在目标小色块上按住左键拖动并松开（单击则选一个像素）。点击“② 点击采激活色”，窗口会暂时收起，等目标激活时点击左键；再用“③ 点击采未激活色”采集同一区域的对立状态。点击位置不改变已选区域。确认两色与容差，使用“检测一次”核对结果。
4. 勾选“色块激活后自动运行当前按键流程”，确认时间默认 100ms，保存。
5. 点击开始或按开始热键，进入蓝色“监听中”状态。**启动时已经亮起不会立即执行**：先让目标恢复未激活至少 100ms，然后再次激活至少 100ms。
6. 自动重复 E 六秒后结束按键，继续监听。一直亮起不会重复触发；必须在本次流程结束后再次观察到稳定未激活，再激活才执行下一次。
7. 点击“全部停止”、停止热键或 Ctrl+Shift+F10，同时关闭监听、取消按键并释放按键。启用单键开关时，主开始键也能停止监听。

未启用颜色触发时，原来的手动限时/无限重复与逐键颜色条件仍可使用。颜色触发模式执行完整的限时流程，不使用逐键颜色门控；触发模式要求持续时间大于零。

## 模块边界

```
ScreenColorReader → ColorMatcher → ActivationEdge → ColorTriggerMonitor
                                                       ↓ workflow 回调
                            RuntimeController → SequenceRunner → IKeySender
```

- `ActivationEdge`：纯状态机，通过单调时间确认连续稳定的激活和恢复；无系统、界面或按键依赖。
- `ColorTriggerMonitor`：50ms 采样循环，条件快照，状态通知，等待流程完成后重新要求未激活；不发送按键，不累计触发，不并发运行流程。
- `RuntimeController / SequenceRunner`：复用现有限时重复和清理；新增 `LastRunFailed` 让流程协调层准确判断执行或释放失败，而不是根据显示文案判断。
- `MainViewModel.Triggers`：界面协调、配置快照、线程切换和总停止；采样在工作线程，执行器生命周期仍由界面线程管理。
- `AutomationEditor`：仅包含绑定和说明；状态区区分蓝色监听、绿色执行、灰色停止。

读取失败、流程执行失败或释放失败会关闭监听并记录错误。流程执行期间不采样、不排队；因此执行期间发生又消失的变化不会作为下一次触发。停止后排队的界面通知和执行回调均检查取消令牌，避免重新启动。

本版本一个选中配置对应一个检测区域和一个现有按键序列，不包含多点逻辑、任意分支或可视化流程编辑器。监视器接收独立工作流回调，后续可以扩展流程步骤而不把业务逻辑加入取色或界面代码。

- 配置 v4：v1/v2/v3 自动加载迁移，旧配置默认关闭颜色触发。保存使用原有原子替换和备份；复制与导入导出保留触发模式及确认时间。

- 新测试：启动时激活、闪烁过滤、持续激活仅执行一次、恢复后再次激活、串行执行、空闲与执行期间停止、采样异常、流程异常、自动结束释放、配置迁移和复制。

像素/区域检测针对可见桌面；遮挡、窗口位置、缩放、动画或颜色变化需要重新取色。100ms 防抖是在约 50ms 采样基础上确认，实际触发时间受系统调度影响，不代表精确实时控制。

## 点击瞬间采集两种状态

- `ScreenClickCapture` 是临时鼠标监听器，使用既有 MouseKeyHook 依赖的独立消息线程；不修改输入输出后端。拖动左键选择区域，采样时只用左键按下作为时刻信号，读取固定区域。按下和弹起均拦下，不把采样点击传给其他程序；松开后撤销临时监听并恢复窗口。
- Esc 或 60 秒超时取消，退出程序也取消；取消不保存半成品。取色期间停用运行热键，避免采样时输出按键。
- 区域使用规则九点 RGB 均值，采集与运行判断使用相同算法；不是整图平均，不适用于复杂图案识别。建议框选小而均匀的状态色块，尽量不要遮住采样点。
- 采集未激活色后自动启用明确对立状态。匹配激活色 → 激活，匹配未激活色 → 未激活，两者都不匹配或同时匹配 → 未知。未知会中断防抖连续计时，不会用于重新准备触发。两色容差范围重叠时保存/开始会拒绝。
- 修改区域后需重采两色。原三秒单点取色仍保留，该操作会恢复单点并关闭明确对立状态模式。
- 新增验证包括九点坐标/均值、负坐标、明确两色与未知分类、未知中断确认、近似两色校验、区域与两色保存加载。真实 Windows 色块测试中，等待临时监听就绪后发送测试鼠标按下/弹起，成功采到固定区域颜色；取消后临时监听退出。没有对目标业务程序发送测试点击。
