# KeyFlow

Windows DD 重复按键工具，.NET 8 / WPF。

## 使用

安装用户：运行 `dist/KeyFlow-Setup-1.1.0-x64.exe`，安装后从桌面或开始菜单打开 KeyFlow。无需另装 .NET。可在 Windows 设置 → 应用 → KeyFlow 中卸载。

源码用户：双击 `Start-KeyFlow.cmd` 构建并启动，或运行 `tools/Build-Installer.ps1` 生成安装包。程序启动请求管理员权限。

1. 点击“准备使用”。此前配置编辑、保存、置顶、开始、停止和热键不可用。
2. 初始化成功后选择配置，点击按键按钮录入首个键，设置重复间隔。
3. 开始后按顺序持续重复，停止键或 Ctrl+Shift+F10 结束。运行时收起配置。

初始化可能触发 Win 菜单或鼠标移动；手动按钮让用户决定初始化时机，不代表消除了厂商副作用。初始化不自动执行序列。失败需重启，不反复加载。

## 配置

支持新建、重命名、复制、删除（至少保留一个）、JSON 导入和导出当前配置。导入追加，不替换现有配置；点击“保存配置”才写入本地。保存使用原子替换并保留 `.bak`。

配置与日志位于 `%LOCALAPPDATA%\KeyFlow\config.json` 和 `keyflow.log`。首次源码运行可复制旧配置且不覆盖已有配置，原文件不删除；本机已有配置已迁移并核对哈希。更新与卸载保留个人数据及系统共享输入组件。

完整构建与验证记录见 [安装交付](docs/KEYFLOW_INSTALLATION.md)。

## 架构

- Core：重复调度、配置存储、运行时。
- Windows：DD 输出、键盘监听、诊断、配置复制与校验。
- App：模块化 WPF；MainViewModel.Setup.cs 负责手动初始化与配置交换。
- tests：核心和 Windows 测试。运行 `dotnet test KeyFlow.sln`。

输出仅用 DD；热键接收使用 MouseKeyHook、Raw Input、系统热键和状态轮询。独立 Demo 和旧启动入口已删除，历史可由 Git 恢复。

参见 [功能调研](docs/FEATURE_RESEARCH.md)、[初始化问题](docs/DD_INITIALIZATION_OPTIONS.md)、[热键研究](docs/HOTKEY_LIBRARY_RESEARCH.md)。研究文件保留历史记录，当前使用方法以本文为准。

## 快速切换与单键开关

准备完成后，配置以卡片列表显示，点击即可切换；当前卡片高亮，数量较多时可滚动。切换会清空步骤选择、取消未完成录入并重新绑定当前配置的快捷键。运行期间不可切换，先停止再选择配置。

开始/停止按钮固定在上方。配置区的“单键开关”勾选后，开始键同时承担停止功能，不再注册原停止键；取消勾选恢复独立启停键。紧急停止 Ctrl+Shift+F10 始终保留。选项按配置保存，复制、导入、导出保留该值；旧配置默认不启用。修改后点击保存配置。

本轮验证：45 项测试通过，涵盖单键模式序列冲突校验、JSON 保存及旧配置兼容、长按重复抑制、两路接收去重和松开再按。通过假数据渲染实际 WPF 控件检查布局，未调用 DD、未在游戏中实测。

## 组合键

按键序列与启停键支持 Ctrl、Alt、Shift 加一个主键，例如 Shift+1、Ctrl+Shift+1。点击按键按钮后，先按住修饰键，再按主键；整组松开后恢复快捷键监听。单独的修饰键在松开时录入。支持原有 D1 格式，新增录入显示 1，配置仍保存字符串。

DD 输出按 Ctrl/Alt/Shift、主键顺序按下，逆序释放；失败按下保留状态供清理，部分释放失败仍继续尝试其他键。校验拒绝可能触发启停键或紧急停止键的序列。暂不支持 Win 组合键或 A+B 这类多个普通主键。

验证：56 项测试通过，新增解析、旧单键兼容、修饰键录入与释放、DD 调用顺序、部分失败清理及快捷键冲突测试。测试使用假 DD 接口，未发送真实组合键，游戏内效果待实测。

## 限时重复与屏幕取色（1.1.0）

例如按 X 或 F 后重复 E 六秒：开始键录入 X、备用开始键录入 F，关闭单键开关，持续时间填 6，序列只保留 E，重复间隔填 80 ms。保存配置后任一开始键触发同一任务，到时自动停止；运行中再次触发不排队、不重置计时。填 0 保留持续运行。停止键和紧急停止仍可提前结束。

展开“屏幕取色与激活判断”，点击“取色（3 秒后）”，把鼠标移到已经激活的目标位置。程序保存该点的物理像素坐标和颜色；“检测一次”比较当前颜色与目标颜色。容差表示各 RGB 通道允许的最大差值（0–255）。每个配置保存一个检测点，不同位置可用不同配置。

可选勾选“仅在颜色匹配时输出按键”：每次按下前检查，未匹配时每 50 ms 重试，匹配后继续原序列，持续时间仍计时；读取失败则停止并清理按键。未勾选时，颜色检测不影响按键输出。读取的是可见桌面，遮挡、窗口移动、缩放或显示模式改变后需要重新取色；单像素匹配并不等于识别应用内部业务状态。

配置升级为 v3；v1/v2 加载后保留原序列，默认不限时、无备用键、关闭颜色条件。不自动写回用户配置，保存才升级。旧版程序不能读取 v3，请保留备份。

设计与测试边界见 [限时重复与取色](docs/TIMED_REPEAT_AND_COLOR.md)。
