# key_flow

Windows DD 重复按键工具，基于 .NET 8 和 WPF。

## 使用

运行 `dist/key_flow_setup_1.5.13_x64.exe` 安装。安装后可从桌面或开始菜单启动，也可从 Windows 设置卸载。程序使用 DD 输入组件，初始化前不会发送按键。

首次启动后点击“准备使用”。在主窗口选择配置组并开启需要的方案；方案按其启停热键触发。编辑配置时可选择单键重复或多键顺序执行，并设定持续或限时重复。

## 按键测试

打开配置编辑器的“流程”页，在“按键测试”中设置 1–30 秒测试时长并点击“试运行”。程序按当前配置中的按键、按住时长和间隔重复执行，结束时自动释放所有按键。“停止测试”可提前结束。试运行使用与正式流程相同的 DD 输出通道，不需要启动全局监听，也不会改变方案设置或保存的持续时间。

测试前请确认目标窗口已处于合适状态；测试时可以使用页面上的“停止测试”，也可以用全局紧急停止键 Ctrl+Shift+F10。

## 配置与开发

配置位于 `%LOCALAPPDATA%\key_flow\config.json`，日志位于 `%LOCALAPPDATA%\key_flow\key_flow.log`。保存采用原子替换并保留备份。旧配置中已经移除的屏幕取色字段会被忽略，其他方案、分组、快捷键和执行流程继续保留。

安装 .NET 8 SDK 后，可运行 `dotnet test key_flow.sln`。使用 `start_key_flow.cmd` 构建并启动，或使用 `tools/build_installer.ps1` 生成安装包。安装器还需要 NSIS 和项目要求的 DD 厂商文件。

Core 负责配置、重复调度和运行时；Windows 模块负责 DD 输出与键盘监听；App 提供 WPF 界面。启停快捷键只观察并放行输入。多个触发请求进入共享 FIFO 激活池，按顺序执行。

完整构建记录见 [安装交付](docs/key_flow_installation.md)。
